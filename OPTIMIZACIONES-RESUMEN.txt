=====================================================
CONFIGURACION REQUERIDA - CRON DEL SERVIDOR
=====================================================

Dado que WP-Cron ha sido deshabilitado (DISABLE_WP_CRON = true),
es necesario configurar un cron job del servidor para ejecutar
las tareas programadas de WordPress.

## Para Laragon (Windows) - Programador de tareas:

1. Abrir "Programador de tareas" de Windows
2. Crear nueva tarea:
   - Nombre: "WordPress Cron - MultiAnalityca"
   - Desencadenador: Cada 5 minutos
   - Acción: Iniciar programa
     - Programa: C:\laragon\bin\php\php-8.3.x\php.exe
     - Argumentos: C:\laragon\www\multianalityca\wp-cron.php
     - Iniciar en: C:\laragon\www\multianalityca

## Para cPanel (Producción):

1. Ir a cPanel > Cron Jobs
2. Agregar nuevo cron:
   - Tiempo: */5 * * * * (cada 5 minutos)
   - Comando: /usr/local/bin/php /home/usuario/public_html/wp-cron.php

## Alternativamente con wget/curl:

*/5 * * * * wget -q -O - https://multianalityca.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1

## O con curl:

*/5 * * * * curl -s https://multianalityca.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1

=====================================================
NOTAS IMPORTANTES
=====================================================

1. CONVERSIÓN WEBP: Las imágenes existentes NO se convierten
   automáticamente. Solo las nuevas imágenes subidas se
   convertirán a WebP. Para convertir imágenes existentes,
   usar un plugin como ShortPixel o Imagify.

2. CACHE: Después de estos cambios, limpiar todos los caches:
   - WP Rocket: Admin > WP Rocket > Clear Cache
   - LiteSpeed: Admin > LiteSpeed Cache > Purge All
   - Navegador: Ctrl+Shift+R

3. TESTING: Verificar el sitio funciona correctamente después
   de los cambios. Si hay problemas, revisar el archivo
   wp-content/debug.log (si WP_DEBUG está habilitado).

4. CRON: IMPORTANTE - Configurar el cron del servidor según
   las instrucciones anteriores para que las tareas programadas
   (emails, optimización de base de datos, actualizaciones)
   sigan funcionando correctamente.
